# Caveat

`Caveat-Medium-latin.woff2` and `Caveat-Medium-latin-ext.woff2` are the static weight 500 files served by Google Fonts, by The Caveat Project Authors. They are the sources for `scripts/subset-fonts.py`.

- Project: https://github.com/googlefonts/caveat
- License: SIL Open Font License 1.1, included in `LICENSE.txt`.

The site serves `caveat-core.woff2` through `next/font/local` and `caveat-extended.woff2` through `app/globals.css`.
